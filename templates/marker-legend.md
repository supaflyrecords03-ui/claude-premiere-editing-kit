# Marker legend

Use one prefix per marker so the timeline reads at a glance.

| Prefix | Meaning | Example |
|---|---|---|
| `DONE` | A note was handled here | `DONE 2: shortened intro by 1s` |
| `FIX` | Something is wrong and needs fixing | `FIX: jump cut on the product shot` |
| `CHECK` | Looks fine but someone should confirm | `CHECK: is this the latest logo?` |
| `MUSIC` | The music needs a decision by the editor | `MUSIC: track ends 3s before picture` |
| `QUESTION` | Needs an answer before it can be done | `QUESTION: which take did the client mean?` |

Keep comments short: what it is, what needs doing.
